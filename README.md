# راهنمای کامل — Tradeiscool v4 (نسخه نهایی)

دو ربات مستقل، هر دو رایگان روی GitHub Actions:

| فایل | کار | هر چند وقت اجرا می‌شود |
|---|---|---|
| `candle_engine.py` | تولید سیگنال (طلا/بیتکوین/اتریوم، ۶ تایم‌فریم) + عکس چارت + خروج R:R، همه به انگلیسی | هر ۵ دقیقه |
| `subscription_bot.py` | پلن‌ها، پرداخت تتر (چند شبکه)، تخفیف، تمدید، لغو، کنترل کامل ادمین | هر ۵ دقیقه |

---

## بخش اول: پیش‌نیازها

1. اکانت گیت‌هاب
2. ربات تلگرام (از `@BotFather`، دستور `/newbot`)
3. یک کانال تلگرام **خصوصی** برای مشترکین پولی
4. (اختیاری) یک کانال عمومی برای نمونه/تیزر
5. کلید رایگان از **twelvedata.com**
6. آدرس یک کیف‌پول ترون (Tron/TRC20) — با `T` شروع می‌شود
7. (اختیاری، برای پرداخت با BNB Chain) آدرس کیف‌پول BNB Smart Chain (با `0x`) + کلید رایگان از **bscscan.com/apis**
8. آیدی عددی خودتان (و هر ادمین دیگری) از `@userinfobot`

---

## بخش دوم: ساخت کانال خصوصی

1. کانال بسازید → Private کنید.
2. ربات را اضافه و **ادمین** کنید با دسترسی‌های `Invite Users via Link` و `Ban Users`.
3. یک پیام از کانال به `@RawDataBot` فوروارد کنید و `chat.id` را بردارید (مثل `-1001234567890`).

---

## بخش سوم: بالا بردن ریپو در گیت‌هاب

1. یک ریپوی **Private** بسازید.
2. همه‌ی فایل‌های این پکیج را در آن آپلود کنید: `candle_engine.py`, `subscription_bot.py`, `requirements.txt`, پوشه‌ی `data/`, پوشه‌ی `.github/`.
3. **Settings → Secrets and variables → Actions** → این‌ها را اضافه کنید:

| Secret | مقدار | اجباری؟ |
|---|---|---|
| `BOT_TOKEN` | توکن ربات | ✅ |
| `PRIVATE_CHANNEL_ID` | آیدی کانال خصوصی | ✅ |
| `TWELVEDATA_API_KEY` | کلید Twelve Data | ✅ |
| `WALLET_ADDRESS_TRC20` | آدرس کیف‌پول ترون | ✅ |
| `ADMIN_USER_IDS` | آیدی‌های عددی ادمین‌ها، با کاما جدا — مثل `111111,222222` | توصیه‌شده |
| `PUBLIC_CHANNEL_LINK` | لینک کانال عمومی | اختیاری |
| `WALLET_ADDRESS_BEP20` | آدرس کیف‌پول BNB Chain | فقط برای BEP20 |
| `BSCSCAN_API_KEY` | کلید BscScan | فقط برای BEP20 |
| `PAYMENT_WINDOW_MINUTES` | مهلت پرداخت (دقیقه)، پیش‌فرض ۴۵ | خیر |

4. تب **Actions** → هر دو ورک‌فلو (`Candle Signal Engine`, `Subscription Bot`) را فعال کنید.

---

## بخش چهارم: تست

- **ربات اشتراک:** `/start` → `/plans` → یک پلن و روش پرداخت انتخاب کنید؛ مبلغ و آدرس را ببینید.
- **موتور سیگنال:** Actions → Candle Signal Engine → Run workflow → `force_run_all=true`. اولین اجرا ۳۰۰ کندل تاریخی برای هر ۱۸ ترکیب نماد/تایم‌فریم می‌گیرد (کمی طول می‌کشد)، و اگر آخرین کندل هرکدام شرایط سیگنال را داشت بلافاصله پیام+چارت می‌آید.

---

## بخش پنجم: منطق سیگنال و حد ضرر (خلاصه فنی)

- ورود: همان منطق کندلی استراتژی شما (هم‌راستایی با EMA7/EMA25، شکل کندل، بدون خنثی‌بودن شیب EMA7، فیلتر کول‌داون و ویپ‌ساو) — **بدون تغییر**.
- **حد ضرر (تغییر این نسخه):** بین دو مقدار زیر، هرکدام فاصله‌ی بیشتری تا قیمت ورود دارد (محافظه‌کارانه‌تر) انتخاب می‌شود:
  1. مقدار EMA7 روی کندل سیگنال
  2. آخرین کف/سقف تشکیل‌شده در ۱۰ کندل قبل از کندل سیگنال (سوینگ لو/های)
  - لانگ → کمینه‌ی این دو؛ شورت → بیشینه‌ی این دو.
- خروج: در R:R های ۳، ۵، ۷ پیام جداگانه؛ اگر مستقیم به حد ضرر بخورد هم پیام «Stop Hit» می‌آید (شفافیت کامل، نه فقط سودها).
- نمادها: BTC/USD، ETH/USD، XAU/USD — تایم‌فریم‌ها: 1m، 5m، 15m، 1h، 4h، 1d.

### ⚠️ محدودیت واقعی API برای تایم‌فریم‌های پایین
پلن رایگان Twelve Data سقف **۸۰۰ درخواست در روز** دارد. چک‌کردن ۳ نماد × ۶ تایم‌فریم دقیقاً در لحظه‌ی بسته‌شدن هر کندل غیرممکن است (فقط ۱ دقیقه‌ای به‌تنهایی ۴۳۲۰ درخواست/روز لازم دارد). زمان‌بندی این نسخه طوری تنظیم شده که در حدود **۷۴۱ درخواست/روز** بماند:

| تایم‌فریم | فاصله‌ی چک | تاخیر احتمالی |
|---|---|---|
| 1 دقیقه | هر ۳۰ دقیقه | تا ۳۰ دقیقه |
| 5 دقیقه | هر ۲۰ دقیقه | تا ۲۰ دقیقه |
| 15 دقیقه | هر ۱۵ دقیقه | تقریباً بدون تاخیر |
| 1 ساعته | سر هر ساعت | بدون تاخیر |
| 4 ساعته | سر بسته‌شدن هر کندل | بدون تاخیر |
| روزانه | ۰۰:۰۰ UTC | بدون تاخیر |

هیچ سیگنالی از دست نمی‌رود، فقط تایم‌فریم‌های پایین ممکن است با تاخیر شناسایی شوند. اگر بعداً پلن Twelve Data را ارتقا دادید، اعداد `is_timeframe_due` در `candle_engine.py` را می‌توانید کاهش دهید.

## بخش ششم: قیمت‌گذاری

بر اساس بررسی بازار، کانال‌های سیگنال مشابه معمولاً ۵۰ تا ۳۰۰ دلار در ماه می‌گیرند (ارزان‌ترین‌ها حدود ۶۶-۷۰ دلار). قیمت‌های پیش‌فرض این ربات:

| پلن | قیمت | معادل ماهانه |
|---|---|---|
| ۱ ماهه | $39 | $39 |
| ۳ ماهه | $99 | ~$33 (۱۵٪ تخفیف) |
| ۶ ماهه | $180 | ~$30 (۲۳٪ تخفیف) |
| ۱۲ ماهه | $300 | ~$25 (۳۶٪ تخفیف) |

پایین‌تر از ارزان‌ترین رقبا، با تخفیف پلکانی که مشتری را به خرید بلندمدت ترغیب می‌کند. این اعداد در بالای `subscription_bot.py` (دیکشنری `PLANS`) به‌راحتی قابل تغییرند.

## بخش هفتم: سیستم تخفیف (جدید)

فقط ادمین می‌تواند کد تخفیف بسازد:

```
/admin_discount_add WELCOME10 10 100 30
```
یعنی: کد `WELCOME10`، ۱۰٪ تخفیف، حداکثر ۱۰۰ بار استفاده، تا ۳۰ روز دیگر معتبر.
(`max_uses` و `days_valid` اختیاری‌اند — اگر نگذارید یعنی نامحدود/بدون انقضا.)

کاربر با `/code WELCOME10` کد را فعال می‌کند، بعد `/plans` می‌زند و تخفیف روی مبلغ پرداختی اعمال می‌شود.

مدیریت بیشتر:
```
/admin_discount_list
/admin_discount_remove WELCOME10
```

## بخش هشتم: کنترل کامل ادمین روی کاربران

```
/admin_list                          → لیست همه مشترکین فعال
/admin_add <user_id> <days>          → افزودن/تمدید دستی
/admin_extend <user_id> <days>       → افزایش زمان اشتراک
/admin_reduce <user_id> <days>       → کاهش زمان اشتراک
/admin_remove <user_id>              → حذف فوری کاربر
```
همه‌ی این دستورات فقط برای آیدی‌هایی که در `ADMIN_USER_IDS` گذاشته‌اید کار می‌کنند. کاربر مربوطه هر بار پیام اطلاع‌رسانی خودکار دریافت می‌کند.

---

## بخش نهم: تجربه کاربری پرداخت (ساده‌ترین حالت ممکن بدون واسط پولی)

۱. کاربر پلن و شبکه (TRC20/BEP20) را با دکمه انتخاب می‌کند.
۲. یک مبلغ دقیق (مثلاً ۳۹.۰۴۷۲ تتر) و آدرس کیف‌پول شما نمایش داده می‌شود.
۳. کاربر همان مبلغ را واریز می‌کند.
۴. کاربر می‌تواند دکمه‌ی «I've Paid — Check Now» را بزند تا فوراً (نه منتظر اجرای بعدی کرون) بررسی شود؛ یا اگر صبر کند، ظرف حداکثر ۵ دقیقه خودکار تایید می‌شود.
۵. لینک ورود یک‌بارمصرف کانال ارسال می‌شود.

چرا مبلغ دقیق؟ چون بدون هیچ سرویس واسط (که کاربر ایرانی/بین‌المللی را رد کند)، تنها راه خودکار تشخیص «این تراکنش مال کدام کاربر است» همین است. این خودش ساده‌ترین روش ممکن برای پرداخت مستقیم به کیف‌پول است.

---

## بخش دهم: بازاریابی و نگهداری

- کانال عمومی = ویترین: نمونه سیگنال با تاخیر یا فقط نتیجه نهایی پست کنید.
- شفافیت (پیام‌های Stop Hit علاوه بر سودها) بزرگ‌ترین ابزار اعتمادسازی شماست.
- یادآوری تمدید ۳ روز قبل از پایان اشتراک خودکار ارسال می‌شود.
- کد تخفیف را می‌توانید برای کمپین‌های تبلیغاتی (مثلاً معرفی از طرف یک اینفلوئنسر) بسازید و فقط به او بدهید.

## عیب‌یابی سریع

- **سیگنال نمی‌آید:** لاگ Actions → Candle Signal Engine را بخوانید؛ اگر `TWELVEDATA_API_KEY` خالی/نامعتبر باشد دقیقاً می‌گوید.
- **کاربر عضو کانال نمی‌شود:** بررسی کنید ربات در کانال خصوصی ادمین با دسترسی `Invite Users via Link` است.
- **پرداخت شناسایی نمی‌شود:** مبلغ باید دقیقاً (تا ۴ رقم اعشار) و روی شبکه‌ی درست باشد؛ دکمه‌ی «I've Paid» را بزنید تا فوراً چک شود.
- **دستورات ادمین جواب نمی‌دهد:** آیدی عددی‌تان را با `@userinfobot` دوباره چک کنید و مطمئن شوید دقیقاً همان عدد در `ADMIN_USER_IDS` هست (با کاما، بدون فاصله اضافه).
